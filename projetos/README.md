# Projetos do ChatGPT

Cada subpasta representa um Projeto do ChatGPT utilizado pela Dipedra.

## Convenção de nome

Use nomes em letras minúsculas, sem acentos e separados por hífen:

```text
projetos/treinamento-comercial/
projetos/conferencia-de-pedidos/
```

## Conteúdo obrigatório

Cada pasta deve conter:

- `README.md`;
- `INSTRUCOES.md`;
- `CHANGELOG.md`;
- pasta `fontes/` com seu próprio `README.md`.

Use `templates/MODELO-PROJETO.md` ao criar um novo Projeto.

Não coloque na mesma pasta fontes de Projetos diferentes apenas porque tratam de assuntos relacionados.
