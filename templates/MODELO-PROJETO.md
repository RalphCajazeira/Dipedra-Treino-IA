# Modelo de pasta para um Projeto do ChatGPT

Crie a seguinte estrutura em `projetos/<slug-do-projeto>/`:

```text
README.md
INSTRUCOES.md
CHANGELOG.md
fontes/
└── README.md
```

## README.md

Deve informar:

- nome do Projeto;
- finalidade;
- público que utilizará o Projeto;
- escopo e limites;
- lista das fontes atuais;
- responsável pela aprovação das alterações.

## INSTRUCOES.md

Deve conter a versão completa, atual e pronta para copiar no campo de instruções do Projeto do ChatGPT.

## CHANGELOG.md

Formato recomendado:

```markdown
# Histórico de alterações

## AAAA-MM-DD

### Adicionado
- ...

### Alterado
- ...

### Removido
- ...
```

## fontes/README.md

Deve listar cada fonte, sua finalidade, versão ou data de revisão e se substitui algum arquivo anterior.
